# IITU Innovation Center - Redesigned Website

## 🚀 Overview

This is a completely redesigned, modern, and minimalistic website for the IITU Innovation Center. The new design features a clean white background with dark blue buttons and accents, creating a professional and innovative look.

## ✨ Key Features

### Design Improvements
- **Modern Minimalistic Design**: Clean white background with strategic use of dark blue (#1e3a8a) accents
- **Responsive Layout**: Fully adaptive design that works perfectly on all devices
- **Professional Typography**: Using Inter and Space Grotesk fonts for modern readability
- **Smooth Animations**: Subtle animations and transitions for enhanced user experience
- **Accessibility**: WCAG compliant with proper focus management and keyboard navigation

### Technical Features
- **Mobile-First Approach**: Optimized for mobile devices with progressive enhancement
- **Performance Optimized**: Fast loading times with optimized images and code
- **SEO Friendly**: Semantic HTML structure with proper meta tags
- **Cross-Browser Compatible**: Works on all modern browsers
- **Progressive Web App Ready**: Service worker support for offline functionality

## 🎨 Design System

### Color Palette
- **Primary Blue**: #1e3a8a (Dark blue for buttons and accents)
- **Secondary Blue**: #1e40af (Lighter blue for hover states)
- **Background**: #ffffff (Clean white background)
- **Text Primary**: #1a1a1a (Dark gray for main text)
- **Text Secondary**: #64748b (Medium gray for secondary text)
- **Light Background**: #f8fafc (Very light gray for sections)

### Typography
- **Headings**: Space Grotesk (Modern, geometric sans-serif)
- **Body Text**: Inter (Highly readable, optimized for screens)
- **Font Weights**: 300, 400, 500, 600, 700, 800, 900

### Spacing System
- **Base Unit**: 16px (1rem)
- **Section Padding**: 80px (5rem)
- **Container Max Width**: 1200px
- **Grid Gaps**: 2rem, 3rem, 4rem for different contexts

## 📱 Responsive Breakpoints

- **Mobile**: < 768px
- **Tablet**: 768px - 1024px
- **Desktop**: > 1024px

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern features including Grid, Flexbox, Custom Properties
- **Vanilla JavaScript**: No frameworks for optimal performance
- **Font Awesome**: Icons
- **Google Fonts**: Typography

## 🚀 Getting Started

1. **Clone or Download** the project files
2. **Open** `index.html` in a web browser
3. **Serve** the files through a local server for best experience:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```

## 🔧 Customization

### Colors
Edit the CSS custom properties in `styles.css`:
```css
:root {
  --primary-blue: #1e3a8a;
  --secondary-blue: #1e40af;
  --background: #ffffff;
  --text-primary: #1a1a1a;
  --text-secondary: #64748b;
}
```

### Fonts
Change fonts by updating the Google Fonts import and CSS font-family declarations.

### Content
All content is easily editable in the HTML file. Images can be replaced by updating the src attributes.
